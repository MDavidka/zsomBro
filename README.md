# 🎮 ZsomBro - Retro Pixel Art Game

A responsive web-based retro pixel art game featuring **Zsomborr** exploring the scenic pixel wilderness!

## 🕹️ Live Demo
Once deployed to GitHub Pages, play online at:
👉 **`https://mdavidka.github.io/zsomBro/`**

---

## ⌨️ Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Move Left / Right** | `A` / `D` or `←` / `→` | ◀ / ▶ Touch Buttons |
| **Jump** | `W` / `Space` / `↑` | **JUMP** Button |
| **Sprint / Run** | `Shift` (hold) | **RUN** Button |
| **Audio (SFX)** | Sound Button | 🔊 / 🔇 Button |
| **Fullscreen** | Fullscreen Button | ⛶ Button |

---

## 🚀 Features

- 🎧 **Custom Character (Zsomborr)** with headphones, dynamic animations (idle breathing, walking bounce, jump tilt, ground shadows).
- 🌄 **Pixel Art Background** with smooth horizontal camera scrolling.
- 🔊 **Web Audio API 8-Bit Synthesizer** for retro sound effects (jump, footsteps, landing).
- ✨ **Pixel Dust Particle Effects** when jumping, running, and landing.
- 📱 **Mobile & Desktop Responsive**: Virtual d-pad and action buttons for phones/tablets.
- 🚀 **Automated GitHub Pages Deployment** via GitHub Actions workflow.

---

## 🛠️ Local Development

To run the game locally:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Then open `http://localhost:8000` in your browser.
